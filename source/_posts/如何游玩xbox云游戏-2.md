## 前言

对于移动端来说，目前Xbox云游戏较好的方式是使用浏览器游玩，比较方便，桌面端方法同理(应该很少有人在Windows上用云游)
Xbox官方文档链接: [如何使用云游戏 | Xbox Support](https://support.xbox.com/zh-CN/help/games-apps/cloud-gaming/about-cloud-gaming)
温馨提示:
1.畅玩云游需要[Xbox Game Pass Ultimate](https://www.microsoft.com/zh-hk/p/xbox-game-pass-ultimate/cfq7ttc0khs0?activetab=pivot%3aoverviewtab)[，可以自行购买，但建议代购](https://www.microsoft.com/zh-hk/p/xbox-game-pass-ultimate/cfq7ttc0khs0?activetab=pivot%3aoverviewtab)

2.iOS需要iOS14及以上版本

3.如果在阅读中有疑问，还烦请耐着性子将全文读完，文中也许会有答案，若仍有疑问，欢迎留言☺️

## 方法

### Android

下载[狐猴浏览器](https://lemurbrowser.com/app/zh/index.html),[并打开它](https://lemurbrowser.com/app/zh/index.html)

轻点下面的工具按键

![轻点下面的工具按键](https://cloud.listfx.top/d/ListFX-Public/blog/IMG_20230131_180405.jpg?sign=-0Jw1egKZ-myHDVzWhszS0qRtm5c7eOStx83aDNdukU=:0)
*轻点下面的工具按键*

弹出这个页面,点击"edge"

![弹出这个页面,点击"edge"](https://cloud.listfx.top/d/ListFX-Public/blog/Screenshot_2023-01-04-12-35-15-021_com.lemurbrowser.exts.jpg?sign=N_vriqjplvGvrIrQmU4l7WrSY0L7bl-yhWDLNVa9OEY=:0)
*弹出这个页面,点击"edge"*

搜索"tampermonkey"，选择第一个(如图)，下载

![搜索"tampermonkey"，选择第一个，下载](https://cloud.listfx.top/d/ListFX-Public/blog/Screenshot_2023-01-04-12-35-50-234_com.lemurbrowser.exts.jpg?sign=jBFUhGJRTH0bD9Ugyglg8wR-ZM0gQYuK6xpcdZGjZB0=:0)
*搜索"tampermonkey"，选择第一个，下载*

轻点"确定"

![轻点"确定"](https://cloud.listfx.top/d/ListFX-Public/blog/Screenshot_2023-01-04-12-36-12-422_com.lemurbrowser.exts(20230106214950).jpg?sign=1cGHQLjX6zPgIMt4v-eYJIu24bPoLO55tRnaFXYfihY=:0)
*轻点"确定"*

*再轻点"安装"*

</details>

访问[Xbox云游戏](https://www.xbox.com/en-US/play)，登录，就可以玩了

### iOS

在[App Store](https://apps.apple.com/cn/app/userscripts/id1463298887)下载"Userscrips"。并启动它

{% note success %}
由于 Userscripts 属于标准的 Safari 扩展，所以在 App Store 安装之后，需要前往 Safari 设置中开启扩展，具体路径是:"设置"![](https://help.apple.com/assets/625460FE538BF8375A6A771F/62546100538BF8375A6A7742/zh_CN/88b2400e45bcf521514b7252cbb2d959.png)  >  "Safari 浏览器"![](https://help.apple.com/assets/625460FE538BF8375A6A771F/62546100538BF8375A6A7742/zh_CN/f8660f96ce0f82918cdf1d0c55951e06.png)  > "扩展" >  Userscripts 
{% endnote %}
{% note warning %}
注意除了打开 Userscripts 之外，在里面的设置中，还需要允许所有网站。但如果你有安全顾虑，请谨慎此操作。
{% endnote %}

打开Userscripts，点击"Set Userscripts Directory"的蓝色按键，自行选择脚本的存放路径(此处不演示)

![自行选择脚本的存放路径](https://cloud.listfx.top/d/ListFX-Public/blog/9FF9B639-36E2-469D-8F57-B537103D536C.jpeg?sign=pwWCoKyPWmfTVd1OfCEJQs4OJhn940WsUeJWITezJXQ=:0)
*自行选择脚本的存放路径*

{% note danger %}
请不要将存放路径选择在"iCloud云盘"，一定要选择在"我的iPhone(iPad)"中
{% endnote %}

打开Safari，访问[Greasy Fork](https://greasyfork.org/zh-CNXbox)，安装[ Xbox Gaming优化整合](https://greasyfork.org/zh-CN/scripts/455741-xbox-cloud-gaming%E4%BC%98%E5%8C%96%E6%95%B4%E5%90%88)

Q:连接上手柄游玩不能震动？可以解决吗？

A:看设备型号。但前提是需要安装[Xbox Cloud Gaming 游戏振动支持](https://greasyfork.org/zh-CN/scripts/451507-xbox-cloud-gaming-vibration)插件才有可能实现

- PC端一般都可以使用震动，如果蓝牙连接的手柄不震动就尝试使用接收器或者OTG来连接。~~现在的手柄都有震动吧？~~

- Android端有点麻烦。以狐猴浏览器为例，在搜索框内输入`chrome://flags/`，将"Gamepad vibration"这一项调整为"Enabled"(如图)。手柄需要使用接收器或者OTG连接设备就行，不要使用蓝牙。如果仍不能请在Xbox云游戏的头像界面关闭震动以防止与脚本冲突。如果还是不能，那就没有办法

![](https://cloud.listfx.top/d/ListFX-Public/blog/Screenshot_2023-01-31-23-39-04-208-edit_com.gamepass.beta.jpg?sign=cnbIxveDkdk6EoWTBBmURKGYD3LYeBzihvymvr0QiFw=:0)

- 对于iOS(iOS和iPadOS):

>
> — Safari没有振动功能（设备振动和手柄振动都没有）需要等有生之年Apple添加支持,需要等有生之年Apple添加支持
